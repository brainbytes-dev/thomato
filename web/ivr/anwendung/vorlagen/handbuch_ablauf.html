Diese Dateien liegen im Dossier der Anerkennung, nicht im Handbuch. Der Ordner sagt ihren Stand: freigegeben zählt beim Prüfbesuch, alles andere nicht. Ein Klick auf den Namen öffnet die Datei. «Ins Handbuch aufnehmen» verknüpft sie, ohne sie zu kopieren: sie bleibt im Dossier und wird oben mit Prüfintervall und Bestätigung geführt.

«Geprüft» hält fest, dass jemand die Datei angeschaut hat und sie so gilt. Bis zum Einreichen{% if dossierfrist %} am {{ dossierfrist | datum }}{% endif %} soll das für jede zutreffen. Läuft eine Datei vorher ab, eine Bewilligung etwa, bekommt sie unter «Frist» ihr eigenes Datum. Prüfen, die Frist setzen und ins Handbuch aufnehmen darf die Verwaltung; ablegen darf, wer schreibt.

Eine geprüfte Datei wird nach «Fertig» verschoben, denn geprüft heisst, dass sie gilt, und beim Prüfbesuch zählt nur, was dort liegt. Wird die Prüfung zurückgenommen, geht sie dorthin zurück, wo sie herkam.
